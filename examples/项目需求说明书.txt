# 投行底稿数字平台 — 项目需求说明书

> 版本：v1.0 | 日期：2026-04-25 | 编制：金融科技部

## 1. 项目背景

当前投行底稿管理存在以下痛点：
- 底稿文件分散存储，检索困难
- 监管检查时调阅效率低
- 版本管理混乱，无法追溯修改记录
- 缺乏统一的文件命名规范

## 2. 建设目标

打造覆盖底稿生成、流转、归档、检查全流程的数字平台。

## 3. 功能需求

### 3.1 底稿录入
- 支持 Word、PDF、扫描件等多种格式上传
- 自动提取文件名、日期等元数据
- 支持批量导入

### 3.2 智能检索
- 基于全文检索的底稿搜索
- 按项目、类型、日期等多维度筛选
- 支持 OCR 识别扫描件文字

### 3.3 版本管理
- 每次修改自动生成新版本
- 支持版本对比和回溯
- 谁改了什么都可追溯

### 3.4 监管调阅
- 一键打包导出底稿包
- 生成调阅清单
- 水印保护

## 4. 技术方案

| 模块 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Vue 3 + Element Plus | 管理后台 |
| 后端 | Spring Boot 3 | 微服务架构 |
| 存储 | MinIO + PostgreSQL | 文件 + 元数据 |
| 搜索 | Elasticsearch | 全文检索 |
| OCR | PaddleOCR | 扫描件识别 |
