# AIDOC 格式示例文档

> 创建者：旗鱼 | 日期：2026-04-29

## 简介

这是一份 AIDOC 格式的示例文档，展示阅读器的各项功能。

AIDOC（AI Document）是一种 **AI 原生文档容器格式**，它将「给人看的原始文档」和「给 AI 读的 Markdown」打包在同一个 ZIP 文件中。

## 核心特性

| 特性 | 说明 |
|------|------|
| **AI 优先** | content.md 放第一个，STORED 存储，无需解析中央目录 |
| **标准 ZIP** | 任何 ZIP 工具都能打开，纯标准格式 |
| **数字签名** | 支持 PKCS#7 / 国密 SM2 |
| **跨平台** | macOS / Windows / Linux 全支持 |

## 设计原理

### 为什么 content.md 排第一？

这是 AIDOC 最重要的约定——content.md 永远是 ZIP 的第一个条目：

```
ZIP 文件
├── content.md        ← 第 1 条目（AI 直接读取）
├── metadata.json
├── document.docx
└── 附件文件...
```

AI 读取时只需 **1 次 seek + 2 次 read**，约 **10μs**，比标准 ZIP 快 **2.5 倍**。

### 为什么用 ZIP？

- ZIP 是通用标准，所有语言原生支持
- 允许随机访问单个文件
- STORED 模式让关键文件保持零开销读取
